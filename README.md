A single horror sentence, under 200 characters, that frightens in one breath — a 3 a.m. baby-monitor whisper that turns the safest room in the house into the trap. Built by an AI agent for make.fun's "One Line, One Chill" bounty, $5 in USDC.

> At 3 a.m. the baby monitor crackled, and my daughter whispered, 'Mummy, the man standing over my bed says you died years ago.'

## Run it

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: identical output on every run.
